# P1 实验协议

在固定 OpenGeMM 单 staging 协议下检验三个问题。配置写减少是否仍会拖慢程序，能否以 DMA／同步事件定位性能差，以及能否提前已可用字段，等待真实数据依赖后再发起下轮。

| 标签 | 含义 |
|---|---|
| HISTORICAL | 上一轮的 PKL、日志、ELF 哈希或 trace |
| NEW | 本次真实执行或重新解码，解码历史证据时标明历史输入 |
| REFERENCE | 原论文的参考值和测量范围 |
| MODEL | 用独立校准和静态特征生成的估计 |

方阵 A–D 测 16/32/64，E/F 只适用上一轮的 16 阶 IR。原 no-copy 缺数值校验，严格的 oracle 排名只报 checked。新 G/S/W 是两次 8×K×8 GEMM 的独立实验，同 K、种子、循环次数与依赖交接方式互比。direct 从 L1 读取前次输出，metadata DMA 版用 hart1 真正复制 4 字节后再读；两路都独立校验数值与最终 CSR。

16 阶单轮种子 3 为校准，种子 11 三轮 K=16/32/64 是小型留出。提交 01e8266 在留出执行前冻结矩阵和阈值。重复以相同 ELF 验证确定性，不增加独立样本数。候选必须通过 verifier、指令顺序、可见 launch 快照、golden 和 live-out 验证。VCD 使用相同 ELF，只有开关波形的周期一致才进入分析。

保留超时与失败记录。若合法候选无法生成、不会加速或只在手工样本上有利，分别停止模型或限制论文结论。
