# 第三阶段科研判断

**NO-GO，现阶段停止投入通用字段级配置调度 Pass，优先转向 P2 的配置接口与编译器协同。** 两条量化算子图的 6 个变化字段全已就绪，原 Both 全部提前。合法真子集相对同布局安全基线最多改善 2 周期，且从未超越原 Both。P1 第二阶段验证的机制仍成立，但本阶段没有找到收益更大的新负载。

| 问题 | 可复核的回答 |
|---|---|
| 1. 可提前机会常见吗 | 在两条已验证图的两个跨 launch 位置中，普通全组机会为 **2/2**，存在真实晚到字段的严格部分机会为 **0/2**。这是两种小图拓扑的局部频率，不能估计真实 AI 部署总体。 |
| 2. 原论文漏掉多少 | 同分母为 **0/2 位置、0/6 已验证合法字段**。之前动态地址校准走到 effectful use-def 后仍有 2 个字段能单独提前，单列校准。 |
| 3. 关键路径上的配置有多少 | 12 个可提前的运行时字段实例中，**6/12** 各自在单字段同布局干预中减少 1 周期。其它字段和首次配置的完整逐指令关键路径未隔离。实际首次 GEMM busy 为 3 cycles，不宜用静态配置数替代关键路径长度。 |
| 4. 最优合法调度改善多少 | 8 个同布局合法时序都确实执行。同布局最佳从 D 追回 **0–3 cycles（最高 0.0451%）**，严格真子集 E 追回 **0–2 cycles（最高 0.0300%）**。 |
| 5. 有新明显受益负载吗 | **没有。** 新图的严格早写最大效应低于第二阶段的 0.11%–0.16%。官方 AD01 已识别 10 次 GEMM，动态/静态批次都在 pinned 模板匹配失败，无法提供周期。 |
| 6. 简单策略离最优多远 | 最强固定 Both 在 **3/4** 格命中全集合经验 oracle。oracle 相对固定 Both 几何平均领先 **1.00181×**，最坏 regret **0.726%**。差距来自已有 Dedup 在一个注意力输入快 48 cycles。 |
| 7. 是否开发新 Pass | **NO-GO。** 已测范围缺乏原算法漏掉且具备实际收益的机会。可以复用只读诊断、语义约束和归因对照，以便新真实负载有证据后复评。 |
| 8. 是否转向 P2 | **是。** 先量测实际接口写成本与捕获时间，定位配置主导的设备或应用段，再比较原子或批量提交机制和编译接口。P2 的系统收益仍需独立实测。 |
